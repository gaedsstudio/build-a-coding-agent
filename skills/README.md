# Agent Skills

This directory is intentionally almost empty in v0.1.

Chapter 13 will turn skills into reusable packages of instructions, examples,
and optional resources that can be loaded only when a task needs them.

Planned examples:

```text
skills/
├── debugging/
├── refactoring/
├── testing/
├── code-review/
├── frontend/
├── backend/
├── mobile/
├── unreal-engine/
└── security-review/
```

A skill should make an agent better at a repeatable workflow without hard-coding
that workflow into the core agent loop.
