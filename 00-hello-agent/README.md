# 00 — Hello, agent

Before tools, planners, sandboxes, or subagents, prove that you can make one model call yourself.

## Run

```bash
python agent.py
```

## What you learn

- what goes into `messages`
- what comes back from the model
- how little code is actually required to cross the API boundary

## What is deliberately missing

This is not an agent yet. It cannot observe or change a codebase.
